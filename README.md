# Legalease: AI-Powered Legal Document Generator

## Run
1. Install Python 3.10+
2. Open terminal in this folder
3. `pip install -r requirements.txt`
4. `python app.py`
5. Open `http://127.0.0.1:5000`

## Included
- Rental Agreement
- NDA
- Employment Agreement
- Legal Complaint Letter
- SQLite history
- PDF download
- Responsive UI

## Note
This starter version uses a local template-based generation engine. An LLM/API can be connected later for more advanced AI generation. Generated documents are drafts and should be legally reviewed.
